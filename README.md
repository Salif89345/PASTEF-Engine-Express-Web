# PASTEF Engine Express — Web

Version web de consultation du programme, des documents de référence et du Quiz.

Ce dépôt contient uniquement les fichiers compilés nécessaires à l’hébergement GitHub Pages. Le projet Flutter de développement est conservé séparément.

Les cartes personnelles, réglages et progression sont conservés dans le navigateur de chaque utilisateur. Le fil Actualité de cette version reste une sélection pilote datée.
